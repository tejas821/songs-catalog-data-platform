# Version floors, not exact pins — deliberately.
#
# An exact pin of pydantic 2.10 has no wheel for CPython 3.14, so pip falls back to
# building pydantic-core from Rust source, where PyO3 0.22 hard-caps at Python 3.13 and
# the install dies. pydantic 2.12 is the first release whose pydantic-core (2.41+) ships
# 3.14 wheels. Floors let pip resolve a prebuilt wheel on every supported interpreter
# instead of pinning the project to one that only works on the machine it was written on.
#
# Verified: clean `pip install -r requirements.txt` + 21/21 tests passing on CPython
# 3.10.20, 3.11.15, 3.13.13 and 3.14.7.
